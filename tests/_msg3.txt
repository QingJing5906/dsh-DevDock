feat(npm): 三个入口各司其职 + 发布前自检 + 纯矢量品牌图标

此前设置、左侧栏、工作区标签页三处显示的是同一个 npm 界面，这是上一版
偷懒的结果。现在按「这个位置的人想干什么」拆开：

- 设置 › npm：账号卡片 + 我的包。唯一能增删/切换账号的地方。
  账号卡片复用 GitHub 账号卡片的类名（dsh-push-acc-card*），两个平台的
  账号区视觉因此天然一致，不需要两套样式。
- 左侧栏 › npm：浏览与搜索。按关键词搜全站，默认显示自己维护的包。
  没有账号管理——未登录时给一句「去设置里添加」，而不是复制一份登录表单。
- 工作区标签页 › npm：项目视角。这个目录的包名/版本、发布前自检、
  依赖是否落后。换目录就是另一套信息。

新增 Host 能力：
- `/npm/search`：关键词搜索全站包（此前只能看自己的）。
- `/npm/preflight`：发布前自检。检查包名与版本格式、包名是否被占用、
  该版本是否已发布、private 字段、README/LICENSE、files、main 指向的文件
  是否存在。分 fail / warn / info 三级，只有 fail 阻止发布。
  实测本插件自身：fail=0 warn=0 pass=6 info=1。

品牌图标改为纯矢量：粗体 D + 蓝点。
上一版把用户提供的 500×500 位图缩到 16px，笔画糊成一团——位图在 2% 的
显示尺寸下必然丢细节。矢量版已用 16/32/512 三档模拟确认可辨识。

顺手修：PlatformMark 在改图标时被误删，verify-render / verify-platform
立刻报 ReferenceError，已补回。
