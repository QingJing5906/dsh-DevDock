## 产品事实（只能用这些，不要编造）

品牌：DevDock
定位：在 DeepSeek Harness（一个开发者用的 AI 客户端）里统一管理研发账号与服务，不用在浏览器标签和终端之间来回切换。
当前是 2.0.0 版本，两个模块已发布：
1. GitHub / Git：多账号切换、仓库浏览与管理、工作区版本树、一键推送/撤回、推送前 Agent 审查
2. npm：多账号、包搜索、列表/卡片视图、打包审查、发布前 Agent 审查、发布与发布前自检
后续规划：Cloudflare（Workers / Pages）

核心亮点（每条都真实存在，突出这几点）：
- 「一个入口，多个平台」：设置页、左侧栏、工作区标签页三个入口固定，平台在入口内部用下拉切换。加平台不增加界面占用。
- 推送前 Agent 审查：规则扫描（抓令牌/私钥/密钥）必跑，模型审查可选；发现阻断级问题会警告但不阻拦。GitHub 推送和 npm 发布共用同一套审查。
- npm 发布前自检：包名/版本格式、包名是否被占用、该版本是否已发布、private 字段、README/LICENSE、files、main 指向的文件是否存在。
- 结果可多选：审查结果每条可勾选，一键复制「修复提示词」直接给智能体。
- 凭据安全：令牌只通过环境变量注入，不出现在命令行和 git 配置里。
- 信息密度可调：一个无级滑杆（85%–125%）控制字号与间距，四个界面同时生效。

## 视觉风格

你那个 skill 的特效能力很强，但请保持克制，不要做成满屏粒子爆炸的「科技感」宣传片。要像 Claude / Anthropic 的产品视频：

- 主色：暖白 #F5F4EE、深炭 #191919、单一强调色赤陶橙 #D97757、辅助石灰 #B8B2A7
- 大量留白，内容居中或左对齐，避免花哨转场（淡入淡出、缓慢位移、细线生长即可）
- 中文文案 + 少量英文术语（GitHub、npm、Cloudflare 保留原文）
- 无 emoji、无感叹号、无「颠覆」「震撼」这类营销词

特效可以用在你觉得点睛的地方（比如「一个入口三个平台」的切换动效、审查结果的扫过动画、信息密度滑杆的缩放演示），但每个画面至少停留 2.5 秒。

## 结构建议（30–60 秒，可微调）

1. 开场 4-6s：一行大字定位，右下角 DevDock 标记
2. 痛点 4-6s：三句短句依次淡入（切仓库要开浏览器 / 令牌散落配置 / 推送前没人再看一眼）
3. 核心卖点「一个入口」8s：三个固定入口 + 平台下拉切换的动效（这是全片最重要的概念，请重点表现）
4. 推送前审查 8s：审查项卡片 → 结果 → 一键复制修复提示词
5. npm 发布 8s：打包审查 → 发布前自检 → 发布
6. 细节 6s：信息密度滑杆 + 凭据安全（两条小点）
7. 收尾 6s：品牌 + 一句定位 + npm 包名 dsh-devdock
